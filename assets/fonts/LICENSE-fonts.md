# Fonts

The fonts of style v4 "Signal" (2026-10-19):

- **Archivo** (variable: width 62-125, weight 100-900), Copyright 2020 The Archivo Project
  Authors (https://github.com/Omnibus-Type/Archivo): SIL Open Font License 1.1. `Archivo-Variable.ttf`.
- **JetBrains Mono** (variable: weight 100-800), Copyright 2020 The JetBrains Mono Project
  Authors (https://github.com/JetBrains/JetBrainsMono): SIL Open Font License 1.1.
  `JetBrainsMono-Variable.ttf`.
- **Instrument Serif** (Regular), Copyright 2022 The Instrument Serif Project Authors
  (https://github.com/Instrument/instrument-serif): SIL Open Font License 1.1.
  `InstrumentSerif-Regular.ttf`.

Downloaded from the Google Fonts repository (github.com/google/fonts, `ofl/`). Not renamed or
modified; widths and weights are picked at runtime with Godot's FontVariation.
