# Untitled Angel Gacha Game (working title)

A mobile idle/AFK gacha RPG in the style of *Idle Angels*: collect angels and demons, build a team,
push through stages, and keep earning rewards while you're away.

Built in **Unity** by a small team. Planning stage: no code yet.
